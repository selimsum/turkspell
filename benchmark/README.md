# Turkspell Benchmark V3

An independent, reproducible benchmark for comparing Turkish Hunspell
dictionaries. Unlike earlier in-repo benchmarks, the dataset is generated by a
seeded pipeline whose construction is documented here — and no dictionary
under test influences dataset contents except as a *negative filter* (see
Fairness).

## Dataset

`turkspell_bench_v3/` (generated, committed):

- `bench_v3_misspelled.csv` — `id,slice,input,gold,frequency_tier,notes`
- `bench_v3_clean.csv` — `id,input,gold,notes` (control set; must be accepted)
- `manifest.json` — seed, counts, SHA-256 of both CSVs

### Slices (2,500 default / 10,000 with `--full`)

| Slice | Share | Source | Example |
|---|---|---|---|
| corpus_real | 40% | High-frequency words rejected by the OSCAR-derived corpus that appear in NO reference lexicon (`rejected_words.csv`) | degil, tesekkur |
| keyboard | 20% | QWERTY-tr adjacent-key substitution on authority words | kalem → kalej |
| diacritic | 20% | ASCII folds: ş→s ğ→g ç→c ö→o ü→u ı→i â→a | kuş → kus |
| phonetic | 20% | nl↔ln metathesis, silent-ğ drop, -acak/-ecek reduction, -iyor elision | yalnız → yanlız |

Clean control: 2,500 authority words (hatted entries excluded to avoid
punishing correct hat-policy enforcement).

## Regenerating

```bash
python benchmark/generate_dataset.py          # default size
python benchmark/generate_dataset.py --full   # 10k
python benchmark/generate_dataset.py --check  # determinism self-test
```

Deterministic under `SEED=20260824`. The KEY adjacency table is built from
ordered lists (not sets) precisely so output is byte-identical across runs.

## Running

```bash
# all dictionaries found under external_dictionaries/ + turkspell itself
python benchmark/run_benchmark.py

# smoke test (100 rows)
python benchmark/run_benchmark.py --only turkspell --limit 100
```

Requires the `hunspell` CLI on PATH (C++; matches Firefox's engine family).
Results land in `results/<date>_<dict>.json` plus a combined `summary.md`.

## Fairness rules

1. **Collision filter** — a candidate "typo" is discarded if it is a valid
   word in ANY of: TDK, tdk_new, Dil Derneği, Zemberek lexicon, or any
   competitor `.dic` under `external_dictionaries/`. A dictionary correctly
   accepting a real word must never count against it.
2. **Same engine for everyone** — all dictionaries are evaluated through the
   same hunspell CLI path.
3. **Space/case normalization** — suggestions compared after Turkish case
   folding (I↔ı, İ↔i) and whitespace collapse, so `hersey → her şey` counts.
4. **Hatted-policy neutrality** — hatted-only authority words were excluded
   from the clean control so dictionaries aren't penalized for their
   circumflex policy.

## Known limitations

- `corpus_real` slice has no gold correction (real observed errors); its rows
  contribute to detection recall only, and c@1 counts "any different
  suggestion" weakly there. Gold-bearing slices drive correction@1/@3.
- Provenance honesty: `rejected_words.csv` derives from the generic OSCAR
  corpus (not from Turkspell's own decisions), but it was curated in this
  repository. Independent replication should re-mine from raw OSCAR.
- Competitor dictionaries are pinned at download time; record versions when
  publishing results.

## Adding a dictionary

Drop it under `external_dictionaries/<name>/` such that a `.dic/.aff` pair
exists (a `dictionaries/` subdir works). Re-run `run_benchmark.py`.
